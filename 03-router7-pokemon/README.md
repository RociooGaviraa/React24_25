# Proyecto de pokemon con uso de React Router V7

Se pretende realizar un proyecto que utilice las siguientes tecnologías:
- React Router Dom en su versión 7
- Contextos globales
- Librería Sonner para notificaciones
- Estilado con Tailwind CSS

El Scaffolding que se va a utilizar es el siguiente:

```text
src/
├── components/
│   └── Navbar.jsx
├── context/
│   └── PokemonContext.jsx
├── layout/
│   └── RootLayout.jsx
├── pages/
│   ├── Home.jsx
│   ├── Search.jsx
│   ├── PokemonDetail.jsx
│   └── Favorites.jsx
├── routes/
│   ├── Router.jsx
│   └── path.js
├── App.jsx
└── main.jsx
```
